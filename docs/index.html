Папки на панели задач Windows

Клик по группе открывает компактное окно с иконками приложений. Четыре группы вместо тридцати ярлыков.

Скачать GitHub

Панель задач кончается на пятнадцатой иконке

Windows не умеет группировать закреплённые ярлыки: ни папок, ни вложенности. После десятка иконок ряд превращается в свалку, которую приходится разглядывать.

Сделано под то, как панелью задач пользуются на самом деле

Открывается мгновенно

Резидент в трее держит окно каждой группы уже собранным. Клик показывает готовое окно, а не запускает новый процесс.

Всё с клавиатуры

Набор текста фильтрует группу, цифра запускает приложение по позиции.

A-Z1-9↑↓EnterEsc

Тот монитор, та сторона

Per-monitor v2 DPI. Окно прижимается к панели задач того экрана, где курсор, включая режим автоскрытия.

Приложения из Store

Упакованные приложения находятся вместе с их AppUserModelID и запускаются через оболочку.

Светлая и тёмная

По умолчанию следует настройке Windows, с акриловым фоном там, где его даёт Windows 11.

Битые ярлыки чинятся

Переехавшее приложение ищется по имени файла и привязывается заново, а не остаётся мёртвой иконкой.

От установки до закреплённой группы

Создать группу

Имя, цвет, число колонок. У группы есть постоянный идентификатор, поэтому переименование не ломает закрепление.

Добавить ярлыки

Перетащить из Проводника, выбрать файл или дважды кликнуть по строке в списке установленных приложений.

Закрепить

Одна кнопка создаёт ярлык и открывает Проводник с ним выделенным. Перетащите его на панель задач, и группа работает.

Вопросы

Почему закрепление не в один клик?

Windows 10 и 11 намеренно закрыли API для закрепления на панели задач, а обходные пути через реестр ломаются обновлениями. TaskbarFold готовит правильный ярлык и отдаёт его выделенным в Проводнике. Последнее перетаскивание за вами.

Нужны ли права администратора?

Нет. Установщик ставит приложение для текущего пользователя, конфиг лежит в %APPDATA%, повышение прав не запрашивается.

Работает ли на Windows 10?

Да, начиная со сборки 1809. Акриловый фон доступен только на Windows 11, на Windows 10 используется сплошной цвет с прозрачностью.

Нужно ли ставить .NET?

Нет. Портативная сборка это один самодостаточный исполняемый файл без внешних зависимостей.

Собирает ли приложение данные?

Нет. Единственный сетевой запрос это проверка обновлений на GitHub, не чаще раза в сутки и никогда не блокирующая интерфейс.
